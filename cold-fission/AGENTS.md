# Cold Fission: instructions for AI coding assistants

Read `CLAUDE.md` in this folder first. It holds the rules for every AI assistant working on this project (which part the user owns, which folders you may edit, the English-only rule, and the checks to run before finishing). Then read `README.md` and the `BRIEF.md` for the user's part.

If the user has not said which part they own, ask: "Which part are you: A (Core), B (Night), C (Tasks) or D (Store and Atmosphere)?"

Only edit that part's folders. Never edit another part's files.
